# NX Ledger for Mac

Official NX Ledger desktop downloads for Apple Silicon Macs running macOS 13 or later.

Download installers from [Releases](https://github.com/Kehl-io/nxledger-releases/releases). Open the DMG and drag NX Ledger into Applications. Once installed, use **NX Ledger → Check for Updates…** for future stable updates.

The first signed release is being prepared; no installer is available yet. This repository hosts release binaries only. Application source is maintained separately.
