# NX Ledger for Mac

Official NX Ledger desktop downloads for Apple Silicon Macs running macOS 13 or later.

Download the signed DMG from the [latest release](https://github.com/Kehl-io/nxledger-releases/releases/latest). Open the DMG, drag NX Ledger into Applications, then launch it from Applications. Apple notarization is included; no security bypass is needed.

Once installed, open **NX Ledger → Check for Updates…**. Automatic checks are enabled by default. Review release notes, choose Download update, then Restart to install when your work is saved. Later keeps the verified download for another time. The automatic-check setting belongs to this Mac user.

Releases include the installer, signed updater archive, checksums and source-version metadata. This repository hosts release binaries only. Application source is maintained separately.
